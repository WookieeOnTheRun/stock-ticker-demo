# Learn more

These guides explain why the Fractional Kelly Stock Analyzer uses the methods it does and how it turns data into
numbers, charts and BUY / SELL / HOLD suggestions. Pick the track that fits you; each page links to its counterpart in
the other track.

> **Educational tool, not investment advice.** Past performance does not predict future results. The app shows what
> history and a set of explicit rules say; it cannot tell you what will happen next.
