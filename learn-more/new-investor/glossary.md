# Glossary

[← Track overview](README.md)

Plain-language definitions of every term used in the new investor track. The page link after each entry shows where
it is explained in context.

| Term | Meaning |
|---|---|
| **Adjusted close** | A day's closing price, corrected for splits and dividends so the history compares fairly. ([page 2](02-returns-and-risk.md)) |
| **Annualized** | Converted to a "per year" figure so different periods can be compared. ([page 2](02-returns-and-risk.md)) |
| **Backtest** | Replaying a rule on past data to see how it would have done. ([page 6](06-testing-ideas-on-the-past.md)) |
| **Base rate** | How often something happened overall, e.g. the share of past periods in which a stock beat T-bills. The model must beat it to show skill. ([page 7](07-the-model-and-the-advice.md)) |
| **Base currency** | The currency all prices are converted into (U.S. dollars by default). ([page 2](02-returns-and-risk.md)) |
| **Benchmark** | What a stock is compared against, by default SPY, a fund that tracks the S&P 500. ([page 4](04-reading-the-risk-tabs.md)) |
| **Beta** | How much a stock tends to move when its benchmark moves. ([page 4](04-reading-the-risk-tabs.md)) |
| **Bootstrap** | Building many "alternative histories" by reshuffling chunks of the real one, to see how much an estimate could vary. ([page 3](03-how-much-to-invest-kelly.md)) |
| **Brier score** | A standard accuracy score for probability forecasts; lower is better. ([page 7](07-the-model-and-the-advice.md)) |
| **Buy & hold** | Staying fully invested all the time; the simple baseline every strategy must beat. ([page 6](06-testing-ideas-on-the-past.md)) |
| **CAGR** | Compound annual growth rate: the steady yearly growth that would turn the starting value into the ending value. ([page 2](02-returns-and-risk.md)) |
| **Calibration** | Adjusting a model so its "60%" really happens about 60% of the time. ([page 7](07-the-model-and-the-advice.md)) |
| **Compounding** | Returns earned on earlier returns; it makes gains grow and losses hard to undo. ([page 2](02-returns-and-risk.md)) |
| **Correlation** | How closely two stocks move together, from −1 (opposite) to +1 (in lockstep). ([page 5](05-building-a-portfolio.md)) |
| **CVaR** | The average loss on the worst days (here the worst 1 in 20). ([page 4](04-reading-the-risk-tabs.md)) |
| **Diversification** | Spreading money across investments that don't all move together, to reduce swings. ([page 5](05-building-a-portfolio.md)) |
| **Dividend** | Cash a company pays its shareholders. ([page 2](02-returns-and-risk.md)) |
| **Drawdown** | How far a price has fallen from its previous peak; the maximum drawdown is the deepest such fall. ([page 2](02-returns-and-risk.md)) |
| **Efficient frontier** | The best achievable mixes: the most expected return for each level of risk. ([page 5](05-building-a-portfolio.md)) |
| **Excess return** | Return above the risk-free (T-bill) rate. ([page 2](02-returns-and-risk.md)) |
| **Factor** | A broad force that moves many stocks, such as the overall market or "value". ([page 4](04-reading-the-risk-tabs.md)) |
| **Fat tails** | Extreme days happening more often than a bell curve predicts. ([page 4](04-reading-the-risk-tabs.md)) |
| **Fractional Kelly** | Using only part of the Kelly answer (half, by default) to allow for uncertainty. ([page 3](03-how-much-to-invest-kelly.md)) |
| **GARCH** | A volatility model that captures stormy days following stormy days. ([page 4](04-reading-the-risk-tabs.md)) |
| **HRP** | Hierarchical Risk Parity: groups similar stocks and balances risk between groups. ([page 5](05-building-a-portfolio.md)) |
| **In-sample / out-of-sample** | Results on the data used to choose a rule's settings / on data it had never seen. ([page 6](06-testing-ideas-on-the-past.md)) |
| **Kelly criterion** | A rule for the share of money to invest so that wealth grows fastest over the long run. ([page 3](03-how-much-to-invest-kelly.md)) |
| **Lookback window** | How many recent trading days the main estimates use (default 252, about a year). ([page 2](02-returns-and-risk.md)) |
| **Overfitting** | Tuning a rule to past quirks so it looks good in a backtest but fails afterwards. ([page 6](06-testing-ideas-on-the-past.md)) |
| **Regime** | A period with a particular market mood; here low, normal or high volatility. ([page 4](04-reading-the-risk-tabs.md)) |
| **Return** | The percentage change in price over a period. ([page 2](02-returns-and-risk.md)) |
| **Risk-free rate** | The interest on very safe short-term government loans (U.S. T-bills). ([page 2](02-returns-and-risk.md)) |
| **Sharpe ratio** | Average excess return divided by volatility: reward per unit of bumpiness. ([page 2](02-returns-and-risk.md)) |
| **Shrinkage** | Pulling a noisy estimate toward a cautious starting point (here, toward zero). ([page 3](03-how-much-to-invest-kelly.md)) |
| **Signal** | A trading rule that decides when to be in or out of a stock. ([page 6](06-testing-ideas-on-the-past.md)) |
| **Stock split** | Replacing each share with several cheaper ones (or the reverse); it doesn't change what you own. ([page 2](02-returns-and-risk.md)) |
| **Survivorship bias** | History looking better than it was because failed companies are missing. ([page 8](08-limits-and-staying-safe.md)) |
| **Ticker** | A stock's short code on an exchange, e.g. `MSFT`; non-U.S. stocks have a suffix such as `.L` for London. ([page 1](01-the-big-idea.md)) |
| **Treasury bill (T-bill)** | A short-term loan to the U.S. government; the app's risk-free investment. ([page 2](02-returns-and-risk.md)) |
| **Turnover** | How much of a portfolio changes hands in a rebalance. ([page 5](05-building-a-portfolio.md)) |
| **VaR** | Value at risk: the loss you'd exceed only on the worst days (here 1 day in 20). ([page 4](04-reading-the-risk-tabs.md)) |
| **Volatility** | How much returns swing around; usually stated per year. ([page 2](02-returns-and-risk.md)) |
| **Walk-forward** | Testing by repeatedly choosing settings on past data and applying them to the next, unseen period. ([page 6](06-testing-ideas-on-the-past.md)) |

For a broader investing glossary, see the SEC's
[investor.gov glossary](https://www.investor.gov/introduction-investing/investing-basics/glossary).
